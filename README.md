# DJ Roofing Website

This is a simple static website ready for free hosting.

## Recommended free hosting: GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository named `dj-roofing`.
3. Upload `index.html` to the repository.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide a website address similar to:
   `https://YOUR-GITHUB-USERNAME.github.io/dj-roofing/`

You can later add photos to an `images` folder and update `index.html`.
